# ⌨️ Charybdis & Scylla (mk2) Wrist Rest / Stand

[![Keyboard](https://img.shields.io/badge/Designed%20for-Charybdis%20%2F%20Scylla%20(mk2)-red)](https://github.com/Bastardkb)

A custom, ergonomic 3D-printable wrist rest / stand designed specifically for **Charybdis** and **Scylla** split ergonomic keyboards in the **mk2** case design by [Bastardkb](https://bastardkb.com/).

## ✨ Features

* **Dual Compatibility:** Separate tailored models for both **Charybdis** and **Scylla** (mk2 case).
* **Source Files Included:** Includes full `.blend` Blender project files if you want to modify, remix, or customize the model further.
* **Ready-to-Print STLs:** Pre-oriented STL files optimized for direct 3D printing.
* **Ergonomic Design:** Helps relieve wrist strain during long typing or gaming sessions.

## 🛠️ Customization & Editing

If you want to tweak the geometry, fit, or angle:
1. Open `models/charybdis wirst rest.blend` in **[Blender](https://www.blender.org/)**.
2. Modify the mesh or adjust dimensions to your preference.
3. Export back to `.STL` for slicing.
